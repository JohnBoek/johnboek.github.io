# Legacy update endpoint

This repository preserves `/SheetSetEditor/version.json` after renaming the original SheetSetEditor source repository to `boeksolutions.sheetseteditor`.

The JSON is an exact copy of the previously public feed, including its product version. It does not publish or trigger a new application release. Current clients use `JohnBoek/boeksolutions.sheetseteditor-releases`.

The repository name `johnboek.github.io` is required by GitHub for this user-site URL; it is an intentional exception to the usual BoekSolutions repository naming convention. Never recreate the old `SheetSetEditor` repository name, because that would break GitHub redirects.

Keep the legacy path and filename unchanged. Change feed contents only as an explicitly requested release or migration operation. Do not add credentials, customer information, or private application code.
